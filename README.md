## ✨ Fitur Utama

Aplikasi ini hadir dengan berbagai fitur modern untuk mendukung proses belajar mengajar:

### 🎯 Core Features
- **📚 Beranda Kursus**: Menampilkan daftar kursus dengan progress bar interaktif
- **🔍 Pencarian Real-time**: Temukan materi dengan cepat melalui search bar
- **🏷️ Filter Cerdas**: Kategorisasi kursus (Terbaru, Remote, Populer)
- **📊 Progress Tracker**: Visualisasi kemajuan belajar per kursus (40%, 28%, dll)
- **👤 Profil Pengguna**: Avatar dan sapaan personal "Halo, Septian!"
- **📱 Bottom Navigation**: Navigasi mulus antar halaman (Home, Kursus, Ujian, Notifikasi)

### 🎨 UI/UX Excellence
- **Modern Neumorphism Design**: Bayangan halus dan efek glassmorphism
- **Animasi Halus**: 
  - Fade slide down/up pada elemen
  - Card float dengan staggered animation
  - Progress bar fill animation
  - Hover effects pada tombol dan card
- **Responsive Layout**: Adaptif untuk berbagai ukuran layar
- **Gradient Accents**: Warna gradien yang eye-catching

### ⚡ Technical Highlights
- **Performance**: CSS animations dengan GPU acceleration
- **Cross-Platform**: Tampilan konsisten di semua browser modern
- **Interactive Elements**: Hover states, transitions, micro-interactions

## ✨ **Fitur Unggulan**

### 🎓 Untuk Siswa (Frontend Publik)
- **📚 Katalog Kursus** – Jelajahi kursus dengan pencarian real-time, filter, dan progress bar.
- **👤 Profil Pengguna** – Avatar, sapaan personal, dan riwayat belajar.
- **📊 Progress Tracker** – Visualisasi kemajuan per kursus dengan persentase dinamis.
- **🔔 Notifikasi** – Update real-time tentang kursus baru, tugas, dan pengumuman.
- **📱 Responsive Design** – Nyaman diakses dari desktop, tablet, maupun smartphone.

### 🛠️ Admin Panel (Backoffice)
- **📋 Manajemen Kursus** – CRUD lengkap untuk kursus, modul, dan materi.
- **👥 Manajemen Pengguna** – Lihat, edit, dan kelola akun siswa & instruktur.
- **📈 Dashboard Analytics** – Grafik pendaftaran, progress siswa, dan statistik platform.
- **⚙️ Pengaturan Sistem** – Konfigurasi global, tema, dan role-based access control.
- **🔐 Autentikasi** – Login aman dengan JWT, proteksi route, dan role-based authorization.
