## ✨ Fitur Utama

Aplikasi ini hadir dengan berbagai fitur untuk mendukung proses belajar mengajar:

*   **📚 Beranda Kursus**: Menampilkan daftar kursus yang tersedia dalam format grid atau list yang rapi.
*   **🔍 Pencarian & Filter**: Temukan materi pelajaran dengan cepat berdasarkan kategori atau tingkat kesulitan.
*   **📄 Materi Pembelajaran**: Menampilkan konten belajar yang kaya, mulai dari teks, gambar, hingga tautan video.
*   **👤 Profil Pengguna**: Setiap pengguna memiliki profil pribadi untuk melacak kemajuan belajar.
*   **📱 Responsif**: Tampilan yang adaptif, nyaman digunakan di berbagai ukuran layar ponsel.
