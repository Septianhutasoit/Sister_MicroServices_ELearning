## ✨ **Fitur Unggulan**

### 🎓 Untuk Siswa (Frontend Publik)
- **📚 Katalog Kursus** – Jelajahi kursus dengan pencarian real-time, filter, dan progress bar.
- **👤 Profil Pengguna** – Avatar, sapaan personal, dan riwayat belajar.
- **📊 Progress Tracker** – Visualisasi kemajuan per kursus dengan persentase dinamis.
- **🔔 Notifikasi** – Update real-time tentang kursus baru, tugas, dan pengumuman.
- **📱 Responsive Design** – Nyaman diakses dari desktop, tablet, maupun smartphone.

### 🛠️ Admin Panel (Backoffice)
- **📋 Manajemen Kursus** – CRUD lengkap untuk kursus, modul, dan materi.
- **👥 Manajemen Pengguna** – Lihat, edit, dan kelola akun siswa & instruktur.
- **📈 Dashboard Analytics** – Grafik pendaftaran, progress siswa, dan statistik platform.
- **⚙️ Pengaturan Sistem** – Konfigurasi global, tema, dan role-based access control.
- **🔐 Autentikasi** – Login aman dengan JWT, proteksi route, dan role-based authorization.
